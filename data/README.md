# SYNTHETIC DATA

All files in this directory are synthetic, generated by `scripts/generate_data.py`. They contain no real student information.

Arguments: `--days 7 --heavy-readers 5 --library-visits 1500 --malformed 5 --seed 42 --students 200 --transactions 1500 --wifi-rows 5000`

Each file includes 5 deliberately malformed rows to exercise rejection accounting.
